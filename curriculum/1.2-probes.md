# Probe Bank — Module 1.2 (Propositional and predicate logic)

## Probe: Tactic ↔ natural-deduction rule correspondence
Difficulty: easy
Misconception it catches: seeing tactics as commands rather than rules
Seed question: "Which natural-deduction rule does `intro` implement,
and which one does `exact (h p)` implement?"
Acceptable answers must mention: `intro` is `→I` (hypothesis shift);
`exact h p` (or `apply h`) is `→E` / modus ponens.

## Probe: Why `∧I` is a pair
Difficulty: easy
Misconception it catches: separating "proof" from "program"
Seed question: "In propositions-as-types, a proof of `P ∧ Q` is what
kind of value? What does this tell you about how `constructor` and
`⟨_, _⟩` behave?"
Acceptable answers must mention: a pair / product; `constructor`
leaves two subgoals equal to the components; `⟨_, _⟩` is the same
value written in term mode.

## Probe: The limit of constructive reasoning
Difficulty: medium
Misconception it catches: thinking everything classical is also
constructive
Seed question: "Name two propositional tautologies from §1.2 that you
can prove constructively, and two that you cannot."
Acceptable answers must mention: provable — De Morgan `¬P ∨ ¬Q → ¬(P ∧ Q)`,
contrapositive `(P → Q) → ¬Q → ¬P`, curry/uncurry, double-negation
introduction. Not provable constructively — `¬¬P → P`, `P ∨ ¬P`,
`¬(P ∧ Q) → ¬P ∨ ¬Q`, `(P → Q) ∨ (Q → P)`.

## Probe: Universal over empty domains
Difficulty: medium
Misconception it catches: thinking `∀ x, P` implies `P` for any `P`
Seed question: "Why did `forall_and_distrib` need the `[Nonempty α]`
instance? What would break without it?"
Acceptable answers must mention: on an empty `α`, `∀ x, A x ∧ P` is
vacuously true, but we cannot extract `P` — we need a witness to
apply the universal to.

## Probe: Existential / universal swap asymmetry
Difficulty: medium
Misconception it catches: assuming the two directions of a quantifier
swap are symmetric
Seed question: "The worked example proved `(∃ x, ∀ y, B x y) → (∀ y,
∃ x, B x y)`. Why is the converse unprovable, even classically?"
Acceptable answers must mention: the first form requires a *single*
`x` that works for all `y`; the second allows `x` to depend on `y`.
Classical counterexample: `B x y = (x = y)`.

## Probe: The role of `cases` vs. `obtain` vs. destructuring `intro`
Difficulty: easy
Misconception it catches: picking the wrong elimination for the data
Seed question: "When would you use `cases h` rather than
`obtain ⟨x, hx⟩ := h`? Give one situation for each."
Acceptable answers must mention: `cases` for multiple constructors
(like `∨`); `obtain` for single constructors with data (like `∃` or
`∧`). Destructuring `intro` is sugar when you're introducing AND
immediately eliminating.

## Probe: Contraposition and the BHK interpretation
Difficulty: hard
Misconception it catches: thinking contraposition is "just algebra"
Seed question: "Under BHK, a proof of `(P → Q) → ¬Q → ¬P` is a program.
What does the program do?"
Acceptable answers must mention: takes a function `P → Q` and a
function `Q → False`, returns a function `P → False`. On input `p`,
it applies the first to get `q`, then the second to get `False`.
This is the content behind modus tollens.
