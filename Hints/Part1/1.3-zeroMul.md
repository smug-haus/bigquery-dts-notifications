## Level 1 — Nudge

Like `zeroAdd`, but for multiplication. Induct on `n`.

## Level 2 — Sketch

- Base case `n = 0`: `0 * 0 = 0` by definition.
- Inductive step: rewrite `0 * k.succ` using `Nat.mul_succ`, then the
  IH collapses the `0 * k` on the right.

## Level 3 — Skeleton

```lean
induction n with
| zero => sorry
| succ k ih => rw [Nat.mul_succ, sorry]
```
