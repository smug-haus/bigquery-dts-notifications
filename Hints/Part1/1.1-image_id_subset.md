## Level 1 — Nudge

`image (fun x => x) s` says there's some `a ∈ s` with `id a = b`.

## Level 2 — Sketch

- Introduce `b` and the membership witness.
- The witness is `⟨a, ha, heq⟩` where `heq : a = b`.
- Rewrite along `heq` to turn `a ∈ s` into `b ∈ s`.

## Level 3 — Skeleton

```lean
intro b ⟨a, ha, heq⟩
sorry   -- rewrite ha using heq, or use `▸`
```
