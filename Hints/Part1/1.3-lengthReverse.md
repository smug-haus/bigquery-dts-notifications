## Level 1 — Nudge

Induct on the list; the cons case wants `lengthAppend`.

## Level 2 — Sketch

- Base case `[]`: both sides are `0` by definition.
- Inductive step `x :: xs`:
  - `(x :: xs).reverse = xs.reverse ++ [x]` — use
    `List.reverse_cons`.
  - `(xs.reverse ++ [x]).length = xs.reverse.length + 1` — use
    `lengthAppend` from the worked examples.
  - `ih : xs.reverse.length = xs.length` closes it after
    associativity clean-up.

## Level 3 — Skeleton

```lean
induction xs with
| nil => rfl
| cons x xs ih =>
  rw [List.reverse_cons, lengthAppend, ih]
  sorry  -- tidy up
```
