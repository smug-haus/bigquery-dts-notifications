## Level 1 — Nudge

Work backwards: given `c`, chase through `g` first, then `f`.

## Level 2 — Sketch

- Goal after `intro c`: `∃ a, g (f a) = c`.
- Use `hg c` to get some `b` with `g b = c`.
- Use `hf b` to get some `a` with `f a = b`.
- Substitute to close the goal.

## Level 3 — Skeleton

```lean
intro c
obtain ⟨b, hb⟩ := hg c
obtain ⟨a, ha⟩ := hf b
exact ⟨a, sorry⟩   -- rewrite with ha then hb
```
