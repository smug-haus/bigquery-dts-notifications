## Level 1 — Nudge

`List.append` recurses on the *first* argument, so inducting on `xs`
is what lets reductions happen.

## Level 2 — Sketch

- Base `xs = []`: `[] ++ [] = []` by definition.
- Step `xs = x :: xs`:
  - Goal reduces to `x :: (xs ++ []) = x :: xs`.
  - Apply IH `xs ++ [] = xs` via `rw`.

## Level 3 — Skeleton

```lean
induction xs with
| nil => rfl
| cons x xs ih =>
  show x :: (xs ++ []) = x :: xs
  rw [ih]
```
